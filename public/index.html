# Сессия инициализирована.

📖 Памятка по правилам 1d10

  • Основная проверка: 1d10 + Характеристика + Навык[cite: 14].
  • Сложность бросков: Успех достигается, если результат равен или превышает целевое значение (от 3+ до 25+)[cite: 14, 15].
  • Степени успеха: Бросок < сложности — провал; бросок ≥ сложности — успех; бросок ≥ сложности × 2 — впечатляющий успех; бросок ≥ сложности × 3 — невероятный успех[cite: 15].
  • Освоение магии: Постепенное заполнение ячеек заклинаний или зелий за сюжетные баллы / броски снижает сложность до нуля[cite: 25, 31].
